Both projects use the same stack. A Google Cloud project is provisioned for you.

- **Authentication:** Google OAuth via Google Identity Platform

- **Hosting:** Google Cloud — deploy to the project provisioned for you

## Evaluation Criteria

Both projects are evaluated on:

1. **Code Quality** (30%)
   - Clean, readable, maintainable code
   - Appropriate abstractions
   - Error handling
   - Testing approach

2. **Technical Accuracy** (30%)
   - Calculations match expected outputs exactly
   - Edge cases handled correctly
   - Data integrity maintained

3. **User Experience** (20%)
   - Intuitive interface
   - Responsive design
   - Helpful error messages
   - Performance

4. **Problem Solving & Communication** (20%)
   - Approach to ambiguous requirements
   - Documentation of assumptions
   - Communication during the project
